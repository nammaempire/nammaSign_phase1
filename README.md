# Reset95 - Mobile App (Phase 1)

Flutter app on a clean feature-first architecture with Riverpod state management.

Reset95 is a Flutter + Firebase ad-tech marketplace for booking LED billboard ad slots. It runs on real Firebase Auth (phone OTP), Cloud Firestore, Storage, Cloud Functions, FCM, plus Crashlytics and Analytics.

## Quick start

```bash
flutter pub get
flutter run
```

No Firebase setup required for Phase 1a. The OTP screen accepts any 6-digit number.

### Layer responsibilities

- **domain/** — Pure Dart. Defines entities and repository contracts. No Firebase imports.
- **data/** — Firebase implementations. Models extend domain entities and add (de)serialization.
- **presentation/** — UI + Riverpod providers. Depends only on domain repositories.

This separation means swapping Firebase for another backend (or mocking in tests) requires changes only in `data/`.

## State management — Riverpod

- Firebase SDK instances live in `shared/providers/firebase_providers.dart`.
- Repository implementations are exposed via feature providers (e.g. `authRepositoryProvider`).
- Reactive auth state is `authStateProvider` (Stream of `AppUser?`).
- Flow controllers use `StateNotifierProvider` with sealed state classes (see `OtpFlowState`).

## Routing — GoRouter

- All route paths live in `lib/app/router/app_routes.dart`.
- The router redirect logic in `app_router.dart` enforces:
  1. First-launch onboarding (stored in SharedPreferences).
  2. Auth required for main shell.
  3. Auto-redirect away from auth screens once signed in.
- Bottom tabs use `StatefulShellRoute.indexedStack` for tab-state preservation.

## Theming

- Dark theme only in Phase 1, matching the Figma palette.
- Always reference `AppColors`, `AppSpacing`, `AppTextStyles` — never hardcode.
- Update colors in `lib/app/theme/app_colors.dart` once the Figma is accessible.

## Firebase setup (Phase 1b - deferred)

Phase 1a is UI-only. When ready to wire Firebase:

- [ ] Uncomment Firebase deps in `pubspec.yaml` and run `flutter pub get`
- [ ] Create a Firebase project at https://console.firebase.google.com
- [ ] Enable Phone Auth, Cloud Firestore, Cloud Storage
- [ ] Add Android app: package name from `android/app/build.gradle`
- [ ] Add iOS app: bundle ID from Xcode
- [ ] `dart pub global activate flutterfire_cli && flutterfire configure`
- [ ] Add `google-services.json` to `android/app/`
- [ ] Add `GoogleService-Info.plist` to `ios/Runner/`
- [ ] Restore `Firebase.initializeApp` in `lib/main.dart`
- [ ] Replace `FakeAuthRepository` binding in `authRepositoryProvider` with a `FirebaseAuthRepository` implementation

```
categories/{categoryId}

```

## Coding conventions

- Single quotes for strings, trailing commas always.
- One widget per file when widgets exceed ~100 lines.
- Prefer `const` constructors; the linter enforces this.
- All async repository methods catch `FirebaseAuthException` / `FirebaseException` and rethrow as our domain `AuthException` / `ServerException`.
- Use `appLogger` (in `core/utils/logger.dart`) instead of `print` / `debugPrint`.
