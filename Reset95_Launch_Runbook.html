1 Turn on real payments (Razorpay) your action

Full steps are in RAZORPAY_SETUP.md. Summary:
  • Create a Razorpay account; start in Test Mode.
  • Get your Key ID and Key Secret (Settings → API Keys).
  • In functions/.env add RAZORPAY_KEY_ID=rzp_test_xxx.
  • Set secrets: firebase functions:secrets:set RAZORPAY_KEY_SECRET and ...RAZORPAY_WEBHOOK_SECRET.
  • Deploy: firebase deploy --only functions; note the razorpayWebhook URL.
  • Razorpay dashboard → Webhooks → add that URL + the webhook secret, event payment.captured.
  • Test with success@razorpay (UPI) — confirm the booking flips to paid/pending review.
  • When live: swap in rzp_live_ keys, add a live-mode webhook, redeploy.

2 Host the legal pages → get public URLs your action

Play needs a public Privacy Policy URL and an Account-Deletion URL. Files are in your legal/ folder.
  • First, fill the [bracketed] placeholders in all three HTML files (legal entity name, address, refund terms).
  • Easiest host — Firebase Hosting: put the 3 HTML files in a folder, then:
# from a folder containing privacy-policy.html, terms-of-service.html, account-deletion.html
firebase init hosting     # choose this folder as "public", single-page: No
firebase deploy --only hosting
  • You'll get URLs like https://<your-site>.web.app/privacy-policy.html.
  • Alternative: drag the 3 files into a GitHub repo → enable GitHub Pages.
  • Save the Privacy Policy URL and the Account-Deletion URL — you need both in Play Console.
Keep this separate from your Flutter build/web hosting so app builds don't overwrite the legal pages.

3 Create the app in Play Console your action

  • Play Console → Create app → name Reset95, Free, App.
  • Set up Internal testing track; add your own email as a tester.
  • Build an AAB: flutter build appbundle --release, and upload it.
  • Accept Play App Signing. Then copy the App-signing SHA-1 & SHA-256 Google shows you…
  • …and add those SHAs to Firebase (Project settings → your Android app) so OTP works on Play builds. Re-download google-services.json if prompted.
The OTP "Play Integrity / reCAPTCHA" error clears once the app is installed from the Play internal-testing track with the Play-signing SHAs registered — sideloaded APKs can't satisfy Play Integrity.
